# Multispectral extended depth of field via stocastic wavefront optimization

Our repository simulate the light propagation through diffractive optical element (DOE), whose modulated transfer function (MTF) is almost invariant to wavelength changes. The incoming incoherent light pass through a diffractive optical element and captured by a multispectral sensor, such as, multispectral filter array (MSFA) or single snapshot compressive spectral imager (CASSI). We introduces a novel wavefront coding approach that leverages stocastic wavefront optimization.
