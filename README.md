# Multispectral extended depth of field via stocastic wavefront optimization

Our repository simulate the light propagation through diffractive optical element, whose modulated transfer function (MTF) is almost invariant to wavelength changes by a wavefront sensor and captured by a multispectral sensor, such as, multispectral filter array (MSFA) or single snapshot compressive spectral imager (CASSI). We introduces a novel wavefront coding approach that leverages stocastic wavefront optimization.
